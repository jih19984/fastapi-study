# 04. Request Body

- 문서: https://fastapi.tiangolo.com/tutorial/body/
- 날짜: 10/27

## 핵심 한 줄
- 매개변수가 경로에 선언되어 있다면, 경로 매개변수로
- 매개변수가 (int, float, str, bool 등과 같은) 단일 타입으로 되어있으면 쿼리 매개변수로
- 매개변수가 Pydantic 모델 타입으로 선언되어 있으면, 요청 본문으로 해석

## 배운 것
- 스웨거 명세서에서 API 응답 타입이 str로 나타나지 않으려면 
타입힌트로 -> return type을 정의해주어야 한다.
- model_dump()는 pydantic 모델을 json 타입으로 변환시켜준다.
