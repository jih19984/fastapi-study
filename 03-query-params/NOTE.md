# 03. Query Parameters

- 문서: https://fastapi.tiangolo.com/tutorial/query-params/
- 날짜: 10/27

## 핵심 한 줄
쿼리 파라미터에 필수값으로 넣을지 선택값으로 넣을지는 기본 값을 넣어주냐 아니냐에 달려있다.

## 배운 것
IntEnum 클래스를 상속받아, 사용자가 입력할 수 있는 값의 범위를 제한하려고 할 때, 클래스 안에 적힌 것들은 변수가 아니라 인스턴스들이다.

## 헷갈렸던 점 / 질문
ItemType이라는 클래스 안에
정의된 것들이 변수라고 생각했는데 변수가 아닌 인스턴스들이였고,
Enum이 내부적으로 이들을 인스턴스로 만들고 name과 value 속성을 저장한다.
